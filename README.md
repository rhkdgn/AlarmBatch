# 연속 알람 생성기 (AlarmBatch)

시작 시간 · 간격 · 종료 시간만 입력하면 **삼성(안드로이드) 기본 시계 앱**에
알람을 자동으로 여러 개 생성해주는 초간단 앱.

예) 시작 9:00 / 간격 5분 / 종료 9:30 → 9:00, 9:05, 9:10, 9:15, 9:20, 9:25, 9:30 자동 생성

---

## 🚀 컴퓨터 없이 APK 받는 법 (GitHub 자동 빌드)

안드로이드 스튜디오 설치 안 해도 됨. GitHub 계정만 있으면 됨.

1. GitHub 로그인 → 오른쪽 위 **＋ → New repository**
   - Repository name: `AlarmBatch` (아무거나)
   - **Public** 선택 → **Create repository**

2. 새 저장소 화면에서 **uploading an existing file** 링크 클릭
   → 이 폴더 안의 **모든 파일과 폴더를 통째로** 드래그해서 올리기
   (`.github` 폴더까지 꼭 같이 올려야 함! 안 보이면 숨김파일 표시 켜기)
   → 아래 **Commit changes** 클릭

3. 저장소 상단 **Actions** 탭 클릭
   → "Build APK" 워크플로가 자동으로 돌기 시작함 (초록 체크 뜰 때까지 5~10분 대기)

4. 완료되면 그 실행 결과 페이지 맨 아래 **Artifacts** 항목에
   **alarm-apk** 이라는 zip이 생김 → 다운로드 → 압축 풀면 `app-debug.apk`

5. 그 APK를 폰으로 옮기고 탭 → "출처를 알 수 없는 앱 설치 허용" 켜고 설치

> ⚠️ 빌드가 빨간 X로 실패하면, Actions 로그의 에러 메시지를 복사해서 물어봐줘. 바로 고쳐줄게.

---

## 📱 쓰는 법

1. 앱 실행 → 시작 시간, 종료 시간, 간격(분) 입력
2. **알람 만들기** 버튼
3. 삼성 시계 앱 열어보면 알람들이 쫙 생성돼 있음

---

## ⚠️ 알아둘 점 (프로젝트 보고서용 한계점)

- **알람 삭제 기능 없음**: 안드로이드는 알람 "생성" 인텐트만 표준 제공하고
  "삭제"는 표준 API가 없음 → 만든 알람은 시계 앱에서 직접 지워야 함.
- **한 번에 너무 많이 X**: 인텐트를 연속으로 쏘는 구조라, 수십 개를 한 번에
  만들면 일부 기기에서 누락될 수 있음. 5분 간격 몇 개 정도는 문제없음.
- 기기 제조사(One UI 등)에 따라 `SKIP_UI` 동작이 조금씩 다를 수 있음.

## 🛠 안드로이드 스튜디오로 직접 열 때

이 폴더를 그냥 **Open**으로 열면 됨. `app/src/main/java/.../MainActivity.kt`에 핵심 로직 전부 있음.
